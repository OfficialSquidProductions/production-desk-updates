# Production Desk iOS 1.5.5 (24)

Screen edges, status and home-indicator areas now follow the selected light or dark theme. Quick Guide aligns with the adjacent settings controls.

On iPad in portrait, Main breakdown now has Script and Breakdown tabs beside Import script. Switching keeps edits, scene selection, selected script text and pane scroll positions. The control remains in portrait mode with the keyboard open; landscape continues to show both panes.

Scene search retains keyboard focus while filtering. Existing portable production files, original PDFs, annotations, schedules and shot lists remain supported without a format migration.

Verification: 41 JavaScript tests; iPad mini and iPhone native/UI suites; focused iPad Pro, keyboard, rotation, safe-area and contrasting-system-theme launch checks; Release device compilation. Physical-device Files providers, AirDrop and very large productions remain device QA items.

Load Demo opens a separate editable fictional production, The Last Cue, with an original three-scene script, theatre breakdown elements, a rehearsal schedule and sample shots. Repeat loads keep existing demo edits; assets are bundled offline and can be disabled before public launch.
