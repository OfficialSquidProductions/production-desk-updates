# Temporary offline demo

Load Demo and Demo guide are visible beside the production selector on iPhone
and iPad. The separate editable The Last Cue sample matches Scenic: one story
scene, Maya/Leo, four shots, two schedules, department breakdowns and an embedded
original two-page lined PDF. Existing productions, old samples and imported
copies remain preserved. Repeat keeps edits; explicit reset changes only the
workspace-owned sample and can be undone.

See [content, feature coverage, ownership and removal](../windows-src/DEMO-CONTENT.md).
Both bundles' shared controllers/assets stay identical. Disable DEMO_ENABLED in
both copies for launch removal; saved sample files remain ordinary editable
productions.
