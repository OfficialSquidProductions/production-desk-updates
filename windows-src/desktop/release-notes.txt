Production Desk 1.4.5 for Windows

Fixes in this release:
- Element names and board IDs save while typing, including before quitting or updating.
- Backups and older workspaces with missing schedules are repaired when opened.
- Blank and duplicate shot numbers no longer block workspace saves.
- Malformed JSON imports and invalid calendar dates show clear errors.
- New Windows installers require an increasing app version so updates are recognized.

Windows 10/11 x64. The single offline EXE includes the full app, Python runtime,
PDF reader and desktop engine. Installation is per user without administrator access.
Existing projects survive updates and reinstalls. This build is unsigned; Windows
may display a SmartScreen prompt.

Published after backend regression tests, packaged-app checks, silent installation,
reinstall/data-preservation checks, and updater version-selection checks pass.
